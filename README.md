# 📊 Sales Performance Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing retail sales data to identify sales trends, profit performance, product performance, and regional business insights using Power BI and Excel.

## 🎯 Project Objectives
- Analyze overall sales and profit.
- Identify top-performing products.
- Understand monthly sales trends.
- Compare regional sales performance.
- Create meaningful business insights.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- DAX
- CSV Dataset

## 📂 Dataset Description
The dataset contains 1,200 synthetic retail order records from 2025.

Key columns:
- Order ID
- Order Date
- Customer ID
- Product
- Category
- Region
- Quantity
- Sales
- Cost
- Profit

## 📈 Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Unique Customers
- Average Order Value
- Profit Margin
- Monthly Sales Trends
- Region-wise Sales Analysis
- Product Performance Analysis
- Category-wise Sales Analysis
